# 📘 Tuition Invoices Guide\n\n> **Module:** Tuition Invoices\n> **Section:** Finance & Accounting\n> **Access Levels:** Director, Admin, Finance Manager, Accountant\n\n---\n\n## 🌐 Overview\nManage student tuition invoices, track payments, and monitor overdue accounts.\n\n## ✨ Key Features\n- Create new invoices\n- View invoice status (Paid, Pending, Overdue)\n- Delete invoices\n\n---\n\n## 🚀 Step-by-Step Instructions\n\n### Viewing Invoices\n\n1. Go to **Tuition Invoices** in the sidebar.
2. You will see a list of all invoices with their current status.\n\n### Creating an Invoice\n\n1. Click **+ New Invoice**.
2. Select the **Student**.
3. Enter the **Amount**, **Due Date**, and **Description**.
4. Click **Save**.\n\n### Marking as Paid\n\n1. Find a pending invoice in the list.
2. Click **Mark as Paid** to update its status.\n\n---\n*For further assistance, refer to the main User Guide or contact your System Administrator.*\n
