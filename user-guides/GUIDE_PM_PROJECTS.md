# 📘 Projects Guide

> **Module:** Projects
> **Section:** Project Management
> **Access Levels:** All Roles

---

## 🌐 Overview
The **Projects** menu acts as a high-level organizational structure. Instead of having hundreds of random tasks scattered everywhere, you group related tasks under a specific "Project" (e.g., "Summer Campus Expansion"). 

## ✨ Key Features
- **Portfolio Tracking:** See all active and completed initiatives in one place.
- **Team Assignment:** Add members to a project so they receive relevant updates.
- **Milestone Dates:** Set clear start and target end dates for large blocks of work.

---

## 🚀 How to Use (Step-by-Step)

### 1. Creating a New Project
- **Step 1:** Navigate to **Project Management > Projects**.
- **Step 2:** Click the **New Project** button to open the **Create New Project** modal.
- **Step 3:** Fill out the high-level details:
  - **Name:** Make it clear and descriptive.
  - **Description:** Provide context on the overarching goal.
  - **Dates:** Select the Start Date and the expected End Date.
- **Step 4:** Click **Create Project** to initialize it.

### 2. Utilizing Projects
- **Step 1:** Once a project is created, click on it to view its internal details.
- **Step 2:** When you go to the "Task Assignment" or "Kanban Board" menus to create new individual tasks, you will now be able to link those tasks back to this specific project, ensuring all work remains neatly categorized.

---

> [!TIP]
> **Pro Tip:** Always define your overarching Projects *before* attempting to create individual tasks! If you skip this step, your Kanban board will quickly become an unmanageable mess of unlinked chores.
