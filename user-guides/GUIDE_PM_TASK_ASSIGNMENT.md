# 📘 Task Assignment Guide

> **Module:** Task Assignment
> **Section:** Project Management
> **Access Levels:** All Roles

---

## 🌐 Overview
The **Task Assignment** menu is a robust list-view interface for managing daily operational work. It allows project managers to break down massive initiatives into small, actionable chunks, assign them to specific people, and enforce deadlines.

## ✨ Key Features
- **Detailed Task Definitions:** Set titles, descriptions, due dates, and priorities.
- **Direct Accountability:** Assign exactly one owner to every task.
- **List Interface:** Preferable to the Kanban board when you need to bulk-edit or rapidly scan hundreds of tasks.

---

## 🚀 How to Use (Step-by-Step)

### 1. Creating and Assigning a Task
- **Step 1:** Navigate to **Project Management > Task Assignment**.
- **Step 2:** Click the **New Task** button to open the **Create New Task** dialog.
- **Step 3:** Fill in the task specifics:
  - **Title:** Be specific (e.g., "Draft welcome email sequence").
  - **Assignee:** Select the exact person responsible.
  - **Project:** Link it to the overarching initiative.
  - **Due Date:** Establish a deadline.
  - **Priority:** Flag it as Low, Medium, High, or Critical.
- **Step 4:** Save the task. It will instantly appear on the assignee's personal dashboard.

### 2. Modifying Tasks
- **Step 1:** Find an existing task in the list view.
- **Step 2:** Click the edit action to open the **Edit Task** dialog.
- **Step 3:** Update the deadline or re-assign the task to someone else if the original owner is on leave.

---
