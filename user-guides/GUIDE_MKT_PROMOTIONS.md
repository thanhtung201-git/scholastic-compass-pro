# 📘 Promotions Guide

> **Module:** Promotions
> **Section:** Marketing
> **Access Levels:** Director, Admin, Marketing Manager, Marketing Staff

---

## 🌐 Overview
The **Promotions** menu is where you design and manage discount codes. By configuring specific codes here, your sales staff can apply them during enrollment to give students percentage-based or fixed-amount discounts on their tuition.

## ✨ Key Features
- **Code Generation:** Create memorable text codes (like "SUMMER2026").
- **Discount Flexibility:** Offer flat fee discounts or percentage cuts.
- **Expiration Controls:** Enforce strict start and end dates to create urgency.

---

## 🚀 How to Use (Step-by-Step)

### 1. Creating a New Promotion
- **Step 1:** Navigate to **Marketing > Promotions**.
- **Step 2:** Click the button to open the **Add New Promotion** dialog.
- **Step 3:** Fill out the required form fields:
  - **Promotion Name *:** An internal descriptor (e.g., "Early Bird Registration").
  - **Promo Code *:** The actual text string (e.g., "EARLYBIRD").
  - **Discount Type *:** Choose between a percentage (%) or a fixed monetary amount.
  - **Value:** Enter the number (e.g., "15" for 15%).
  - **Start Date * & End Date *:** Define the exact window this code is valid.
  - **Status:** Set it to Active to allow immediate use.
- **Step 4:** Save the promotion.

### 2. Managing Active Promotions
- **Step 1:** Review the main tracking table. It lists all offers under columns: **Code, Name, Discount, Start Date, End Date, Status, and Actions**.
- **Step 2:** If a promotion needs to be extended, use the **Actions** menu to open the **Edit Promotion** dialog and change the End Date.
- **Step 3:** If you need to immediately stop an offer, edit it and change the Status to inactive.

---

> [!TIP]
> **Pro Tip:** Keep your Promo Codes short, capitalized, and easy to type! It reduces the chance of reception staff making typos when entering them into the Finance billing system.
