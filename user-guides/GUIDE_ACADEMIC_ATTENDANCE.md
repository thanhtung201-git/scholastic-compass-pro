# 📘 Academic Attendance Guide

> **Module:** Attendance
> **Section:** Academic
> **Access Levels:** Director, Admin, Academic Manager, Academic Staff

---

## 🌐 Overview
The **Academic Attendance** menu is designed for teachers and teaching assistants to take daily roll call for students. This data is vital for tracking student engagement, triggering parent follow-ups, and managing class utilization.

## ✨ Key Features
- **Digital Roll Call:** One-click attendance marking for entire classes.
- **Rapid Status Updates:** Dedicated quick-action buttons for common attendance states.
- **Class Context:** Attendance is tied directly to specific scheduled lesson dates.

---

## 🚀 How to Use (Step-by-Step)

### 1. Taking Attendance
- **Step 1:** Navigate to **Academic > Attendance**.
- **Step 2:** Select the specific Class and Date from the filters at the top of the screen to load the correct student roster.
- **Step 3:** For each student in the list, use the primary action buttons:
  - Click **Present** if they are in the room.
  - Click **Late** if they arrived after the bell.
  - Click **Absent** if they did not show up.
- **Step 4:** The system records these button presses immediately, ensuring real-time data syncs with the front reception desk.

### 2. Reviewing Absences
- **Step 1:** If a student is marked as "Absent", it may be helpful to add a note (e.g., "Parent called in sick") if the interface supports it.
- **Step 2:** The Academic Manager can review aggregated attendance history to identify students who have missed consecutive sessions.

---

> [!TIP]
> **Pro Tip:** Encourage teachers to execute attendance within the first 10 minutes of class. If a young student is marked "Absent" unexpectedly, the reception team can see this in real-time and call the parents to ensure the child's safety.
