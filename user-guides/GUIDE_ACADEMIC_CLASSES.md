# 📘 Classes Guide

> **Module:** Classes
> **Section:** Academic
> **Access Levels:** Director, Admin, Academic Manager, Academic Staff

---

## 🌐 Overview
The **Classes** menu is where you define the specific cohorts of students, assigning them a course curriculum, a teacher, a schedule, and a physical location.

## ✨ Key Features
- **Class Creation:** Link a Course Offering, Teacher, and Classroom together.
- **Capacity Management:** Prevent over-enrollment by setting strict maximum capacities.
- **Class Lifecycle:** Track whether a class is "Active" or "Ended".

---

## 🚀 How to Use (Step-by-Step)

### 1. Creating a New Class
- **Step 1:** Navigate to **Academic > Classes** in the sidebar.
- **Step 2:** Click the **Create Class** button to open the "Create New Class" dialog.
- **Step 3:** Fill in the class logistics in the form fields:
  - **Class Name:** Give it a distinct name (e.g., "IELTS-A03").
  - **Course Offering:** Select the curriculum template this class follows.
  - **Teacher:** Assign the primary instructor.
  - **Classroom & Branch:** Specify where the class physically takes place.
  - **Start Date:** When does the first lesson begin?
  - **Max Capacity:** Set the maximum number of students allowed.
- **Step 4:** Click **Create Class** to save.

### 2. Editing Class Details
- **Step 1:** Locate the class you wish to modify in the dashboard view.
- **Step 2:** Click the actions menu and select **Edit Class**.
- **Step 3:** In the "Edit Class" dialog, you can modify the **Status** (changing it from Active to Ended) or update the room assignment if you need a larger space.
- **Step 4:** Click **Save Changes**.

---

> [!WARNING]  
> **Warning:** You cannot delete a class if there are still students enrolled in it. You must first transfer those students to a different class via the Students menu or mark them as "Dropped Out" before the system will allow you to delete the class record.
