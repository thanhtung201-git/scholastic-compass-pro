# 📘 Teachers Guide

> **Module:** Teachers
> **Section:** Human Resources
> **Access Levels:** Director, Admin, HR Manager, HR Staff

---

## 🌐 Overview
The **Teachers** menu acts as a specialized directory specifically for instructional staff. Because teachers have unique data points—like hourly rates and subject specializations—they are managed here rather than in the general "Employees" menu.

## ✨ Key Features
- **Academic Directory:** Quickly look up contact information for instructors.
- **Rate Management:** Easily view the hourly pay rates that dictate payroll calculations.
- **Branch Tracking:** See which campuses your teachers operate out of.

---

## 🚀 How to Use (Step-by-Step)

### 1. Browsing the Teacher Roster
- **Step 1:** Navigate to **Human Resources > Teachers**.
- **Step 2:** The dashboard presents a streamlined table with columns for: **Name, Subject, Branch, and Hourly Rate**.
- **Step 3:** Use this table to quickly verify that a teacher is assigned to the correct subject and physical campus.

### 2. Verifying Hourly Rates
- **Step 1:** Before running end-of-month payroll, you can use this table to quickly audit the **Hourly Rate** column for all teachers.
- **Step 2:** If a teacher recently received a raise, verify that their new rate is reflected here so the system calculates their next payslip correctly.

---

> [!WARNING]  
> **Warning:** Changes to a teacher's Hourly Rate usually only apply to *future* payroll calculations. If you need to adjust a payment for a class that already happened, you must handle that manually during the Payroll generation process.
