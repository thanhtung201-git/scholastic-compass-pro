# 📘 Homework Guide

> **Module:** Homework
> **Section:** Academic
> **Access Levels:** Director, Admin, Academic Manager, Academic Staff

---

## 🌐 Overview
The **Homework** menu allows teachers to assign tasks to specific classes and grade student submissions. It provides a structured way to track academic performance outside of the classroom.

## ✨ Key Features
- **Assignment Creation:** Distribute homework to an entire class at once.
- **Grading Interface:** Quickly score assignments and provide written feedback.
- **Draft Mode:** Save assignments as drafts before officially publishing them to students.

---

## 🚀 How to Use (Step-by-Step)

### 1. Creating a New Assignment
- **Step 1:** Navigate to **Academic > Homework**.
- **Step 2:** Click the button to open the **New Homework Assignment** modal.
- **Step 3:** Fill out the assignment details:
  - **Title:** The name of the assignment (e.g., "Chapter 4 Math Worksheet").
  - **Class:** Select the specific class this is assigned to.
  - **Due Date:** The deadline for submission.
  - **Instructions / Description:** Provide detailed instructions on what needs to be done.
- **Step 4:** You can either click **Save Draft** to work on it later, or **Submit** to publish it to the class immediately.

### 2. Grading Submissions
- **Step 1:** Once an assignment is active, you will see a grading table.
- **Step 2:** The table includes columns for **Student, Assignment, Status, Score /10, Feedback, and Action**.
- **Step 3:** Review the student's work, enter a numerical score in the **Score /10** field, and type any constructive notes in the **Feedback** column.
- **Step 4:** The student will be able to see their updated status and feedback immediately!

---

> [!TIP]
> **Pro Tip:** Always utilize the "Feedback" column. A numerical score is helpful, but written feedback is what actually helps the student improve for the next assignment.
