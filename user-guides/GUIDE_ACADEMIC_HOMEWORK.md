# 📘 Homework Guide\n\n> **Module:** Homework\n> **Section:** Academic\n> **Access Levels:** Director, Admin, Academic Manager, Academic Staff\n\n---\n\n## 🌐 Overview\nAssign homework to classes and track student submissions.\n\n## ✨ Key Features\n- Create assignments\n- Set due dates\n- Track student completion\n\n---\n\n## 🚀 Step-by-Step Instructions\n\n### Assigning Homework\n\n1. Click **Homework**.
2. Click **+ Add Homework**.
3. Select the Class, Title, Description, and Due Date.
4. Click **Save**.\n\n### Tracking Submissions\n\n1. Open a homework record.
2. Toggle the submission status next to each student's name.\n\n---\n*For further assistance, refer to the main User Guide or contact your System Administrator.*\n
